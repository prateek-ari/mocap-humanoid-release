Scope

Simulation-only kinematic motion preview. Joint-range and stale-stream checks run in the simulator. No robot SDK or hardware commands are sent.

The ROS 2 preset is the Windows streaming configuration. The live comparison goes directly into Python/GMR, without a ROS 2 node in the middle.

The 30-second acceptance stage and the live viewer run sequentially because both bind UDP 5555. Source and destination IPs may change after reconnecting the network. The commissioning session used Windows 192.168.1.167 and Linux 192.168.1.24. Supply the current addresses and measured performer height for each session.
